# lics-enigma.github.io

Landing page da LICS. HTML, CSS e JavaScript puros, sem build e sem
dependências. Servida direto pelo GitHub Pages a partir
da raiz da branch `main`.

## Arquivos

```
index.html          página
style.css           estilos (#071727 / #ffffff / #f3b5d4)
script.js           glifos, terminal e pistas
robots.txt          aponta para humans.txt
humans.txt          o caminho, para quem procura
.nojekyll           desliga o processamento Jekyll do Pages
assets/favicon.png  ícone (falcão)
```
